เรื่อง Integrated Project
- อาจารย์ได้เเนะนำว่าตรงส่วนของปุ่ม ok ใน dialog box ทางที่ดี 
เราไม่ควรเขียนใน html เเต่ควรเขียนเป็น JavaScript เเทน เพราะในอนาคตหากมี label เพิ่มจะจัดการลำบาก
- ส่วนเรื่องการจัดการ file, folder ต่างๆของ Integrated Project ก็ทำได้ดีเเล้วมีสัดส่วนชัดเจน

สิ่งที่ได้เรียนรู้เพิ่มเติมหลังจากลองทบทวนเนื้อหาในวิชานี้อีกครั้ง (Preparation for Final Exam)
- จากการลองทำ quote manager project ในส่วนของการ edit กับ add จะเเอบสัมพันธ์กัน
เพราะถ้ามีค่า quote id อยู่เเปลว่าเราจะทำ edit แต่ถ้าไม่มีจะเป็นการ add (POST)
- ถ้าอยากจะทำ PATCH ก็คล้ายๆการทำ PUT เเต่ต่างกันที่จาก item ให้ส่งเป็นบาง prop ที่ต้องแก้
- ลำดับการเขียนใน file JS สำคัญไม่งั้น code อาจทำงานผิด
- สื่งที่คนเข้าใจผิดเยอะคือ json() ม้ันไม่ได้ให้ผลเป็น JSON เเต่มันให้ผลเป็น js object
